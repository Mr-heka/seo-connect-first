# SEO Connect First

Tells you what to connect before a Claude SEO audit, in what order, checks the data belongs to your own site, and turns the report into a fix list with an owner.

**Who it is for:** Owners who want to know why customers cannot find them on Google, and want a report they can trust.

**What you need:** Claude Code or Codex, your website address, and access to your Google accounts for the site. The free Claude SEO plugin runs the audit.

## Install

Open `SETUP-PROMPT.md`, copy the prompt in it, and paste it into a new Claude Code or Codex chat. It installs this skill and starts it. It keeps your existing skills as they are.
